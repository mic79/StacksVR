# StacksVR

Battleblocks-inspired WebXR cup stacking (A-Frame + PeerJS).

## Play

- GitHub Pages: after enable, `https://mic79.github.io/StacksVR/`
- Quest Browser → Enter VR
- Multi: menu (X/M) → Multi Lobby → same lobby number

## Local

`python -m http.server` from this folder, or any static server.
